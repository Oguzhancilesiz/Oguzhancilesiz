# Merhaba, ben Oğuzhan 👋

Full-stack geliştiriciyim. Backend tarafında **C# / .NET**, frontend tarafında **Next.js / React**, mobilde **Expo (React Native)** ve **.NET MAUI** ile çalışıyorum. Fikirden canlıya kadar ürün geliştirmeyi seviyorum: veri modeli, API, web, mobil ve deploy.

## 🚀 Şu an üzerinde çalıştığım: [PTFraoula](https://ptfraoula.com)

Online kişisel antrenörlük platformu. Canlıda, gerçek kullanıcıları var. Kaynak kodu özel bir monorepoda tutuluyor.

- **Backend:** .NET 10 Web API, EF Core, SQL Server, JWT ve Google OAuth
- **Web:** Next.js. Tanıtım sitesi, koç paneli ve öğrenci uygulaması ayrı subdomain'lerde
- **Mobil:** Expo / React Native. Öğrenci ve koç modu, push bildirimleri, uygulama içi satın alma, canlı yayın
- **Altyapı:** Railway üzerinde deploy, otomatik migration, lint, typecheck, test ve build kalite kapıları

Ürünün ilk sürümü açık kaynak: [FraoulaPT](https://github.com/Oguzhancilesiz/FraoulaPT) (ASP.NET Core MVC + SignalR). Web katmanından bir kesit: [fraweb](https://github.com/Oguzhancilesiz/fraweb).
